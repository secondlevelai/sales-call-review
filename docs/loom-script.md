# 90-second setup Loom (script)

**0:00–0:10 · Face on camera.** "Here's how to get Sales Call Review running in about a minute. It grades every sales call your team recorded, free."

**0:10–0:30 · Claude → Customize → Plugins.** Click Add, then Add marketplace, paste `bingobuildsai/sales-call-review`, click Add, then install Sales Call Review. "One paste, that's the install."

**0:30–0:45 · Connectors tab.** Click Connect on Fathom (or Fireflies) and sign in. "If you want the whole team, make sure their calls are shared to you; the link's in the description."

**0:45–1:15 · New chat.** Type "Review last week's sales calls." Show the confirmation list grouped by closer, say "grade all," and scroll the report: the headline, one closer's section with a quote and "say this instead," the objection table.

**1:15–1:30 · Face on camera.** "That's it. Run it every Monday. If it helps, star the repo."
