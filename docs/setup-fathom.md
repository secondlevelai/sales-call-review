# Fathom setup

## Connect

In Claude: **Customize → Plugins → Sales Call Review → Connectors → Fathom → Connect**, then sign in to Fathom.

## Review the whole team

The plugin can only see the calls **your** Fathom account can see: calls you recorded, plus calls shared with you or your team. To review every closer, do one of these:

**Option A: a Sales team (recommended)**
1. In Fathom, create a team called **Sales** and add your closers.
2. Make sure their sales calls are **shared to the Sales team** (each closer can set this, or set it as the team default).

**Option B: Admin access**
A Fathom Admin can be granted **view access to all shared calls**. Connect the plugin with that Admin's account.

**Private calls** (not shared with anyone) are only visible to the person who recorded them, so they can't be included. Ask closers to share sales calls.

## Tips

- Name sales calls consistently ("Strategy Call: [Lead] <> [Closer]") or use a Fathom **meeting type** for them, so internal meetings are never mistaken for sales calls.
- For one closer, ask: "Review Dev's calls from last week." The plugin filters by who recorded the call.
